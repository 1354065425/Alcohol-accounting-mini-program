# 臻酒阁 · 酒类经营记账小程序

原生微信小程序，面向单人经营和个人酒窖，包含日常记账、库存管理、流水查询、月度报表，以及本地备份恢复。无第三方运行时依赖，无需自建服务器。

## 已实现

- 售酒、进货、经营支出三种记录；按单价和瓶数计算或直接填总额，记录客户、供应商、付款方式与备注。
- 草稿恢复、连续记账、编辑删除、库存差额联动、防重复提交。
- 日期、区间、收支类型和关键词查询；按天分组与分页；月度现金收支、销售排行和每日走势图。
- 酒名搜索、常见酒名预置、酒名自定义记忆；库存默认隐藏零库存，管理模式可查看全部。
- 品牌、规格、酒类、建议售价与库存预警；库存盘点原因、调整历史和出入库记录。
- 完整备份（JSON／TXT）、CSV表格、文件或文本恢复、最近5个本地恢复点。
- 原有版本数据自动迁移，保留旧数据原稿；新安装从空账本开始。
- 数据与设置、使用帮助、文件恢复隐私授权及版本更新提示。

## 运行

用微信开发者工具导入本目录，使用项目已有AppID与有开发权限的微信账号。编译后扫码预览。无需安装npm运行依赖。

## 数据规则

账本保存在当前微信设备本地，不提供账号、云同步或多人共享。换设备或清理微信数据前，应先导出完整备份，文件生成后点击「发送备份文件」并选择微信会话保存。发送不成功时可以重试、切换TXT格式或使用文本备份；JSON与TXT中的备份内容相同，均可恢复。CSV只用于查看，不能用于恢复。自动恢复点也在本机，不能替代外部备份。

记账以实际收付款为准，现金结余不是利润。本版本不处理赊欠款、纳税、线上支付或售酒订单。进货更新当前库存均价；修改、删除历史流水只修正数量，不追溯重算后续均价，可在库存管理中手动调整成本并填写原因。

统一数据键为 zjgBookV2。升级时自动迁移 cellarEntries、cellarStock、cellarLiquorCatalog 并保留旧键作安全原稿。单账本限制900KB，恢复点最多5份；到达限制会提示备份而不会静默丢弃数据。
